Before you write

These are the questions that come up most, with the answer that works today.

I bought something and the game did not give it to me

Every purchase is checked on our server before the game unlocks anything, so an item can take a moment to appear, and longer if the phone has no connection. Open the game, tap Boost and then Shop, and use Restore Purchases. If it still does not appear, write to us with the store receipt and the install identifier below; nothing you paid for is lost.

I watched an ad and got no Boost Token

Rewards are paid only after the ad network confirms the view to our server. While that is pending the game shows the view as being verified, and it settles on its own, including on the next time the game is opened. If a reward is still missing a day later, write to us with the install identifier.

I reinstalled the game and my progress is gone

Progress is saved on the device, not in an account. Uninstalling the app deletes it. Purchases are not lost: they come back with Restore Purchases. Cloud saving is not built yet.

I want my data deleted

The game has no account and never learns who you are. What exists on our server is tied to a random install identifier. To have it deleted, send that identifier to the address above and say you want it removed. You will find it in the game under Settings, where a button copies it.

What is collected, and why, is described in the privacy policy.

I found a bug, or the game is unbalanced

Write. Say what the screen showed, what you expected, and which phone you use. Balance complaints are as welcome as crashes: the pacing of the game is measured, and a player who says where it drags is doing the most useful thing anyone can do for it.
